# OpenAI API Setup Guide

## Optional: Enable GPT-4 Explanations

The loan prediction app works without an OpenAI API key using enhanced fallback explanations.

### Step 1: Get Your API Key
1. Visit https://platform.openai.com/api-keys
2. Sign in or create an account
3. Click "Create new secret key"
4. Copy your API key

### Step 2: Create Environment File
Create a file named `.env` in the project root with:
```
OPENAI_API_KEY=your_actual_api_key_here
```

### Step 3: Restart the App
The app will automatically detect the API key and enable GPT-4 explanations.
